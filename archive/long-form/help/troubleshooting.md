# 按症状排查

按顺序检查，确认一个原因后再改下一项。先记录错误提示，重装应用应是后续选项。

## 无法连接服务器

1. 对照原始信息检查协议、域名、端口和首尾空格。
2. 确认没有把销售平台网址当成播放地址。
3. 用管理员提供的网页入口测试是否可达。
4. 在另一网络测试；若证书报错，检查地址和设备时间，交由管理员修复证书。
5. 向管理员确认服务状态、远程访问权限和地址是否变更。

**判断**：多个设备和网络都无法连接时，优先核实服务端，不要只在客户端反复操作。

## 用户名或密码错误

确认使用的是服务器本地账号，而非服务商网站或 Connect 账号。检查大小写、空格、账号有效期及是否被禁用；无法确认时联系管理员重置。

## 能看到海报但无法播放

1. 换一部常见编码的影片，区分单文件与全局问题。
2. 关闭字幕或切换 SRT，换一条兼容音轨。
3. 查看是否显示播放解锁或 Premiere 提示，按[授权说明](/guide/costs)处理。
4. 用官方客户端对比，并记录是否尝试视频转码。
5. 若管理员禁用转码，改用可直放的客户端或文件版本。
6. 只有某个文件失败时，请管理员检查源文件、挂载和媒体访问路径。

## 播放卡顿或频繁缓冲

先看实际播放方式。**直放卡顿**优先比较网络、码率和设备解码；**转码卡顿**还要检查服务器处理能力。

- 用同一片源比较两个网络，或同一网络比较两个码率版本。
- Wi-Fi 信号弱时靠近路由器或用有线连接测试。
- 避开后台大文件下载进行对照测试。
- 降低质量前确认服务器允许且有能力转码。

如果只有某个时段慢，记录时段与运营商，交给服务方定位。

## 没有字幕或没有声音

在播放菜单明确选择字幕和音轨，不只改全局语言偏好。试用简单文本字幕、兼容音轨，并检查系统输出设备。详见[字幕、音轨与 HDR](/playback/subtitles)。

## HDR 发灰或画面偏色

先播放 SDR 版本。如果 SDR 正常，核对 HDR 格式、设备支持、显示输出与转码色调映射；不要默认网络问题会导致色彩异常。

## 进度不同步或媒体库为空

确认两个客户端连接的是同一台服务器和同一用户。检查网络是否允许状态回写；媒体库为空时请管理员核对用户权限。第三方客户端的同步行为可能与官方客户端不同。

## 联系管理员时提供什么

复制下面模板，填入非敏感信息。不要公开密码、访问令牌、带凭据的链接或完整日志。

```text
发生时间：
设备 / 系统版本：
客户端 / 版本：
网络类型 / 运营商：
问题现象与错误提示：
影响范围：所有影片 / 某个文件
播放方式：直放 / 直串 / 转码 / 未知
已做对比：另一网络、另一客户端、关闭字幕等
```
