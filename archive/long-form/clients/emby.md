# Emby 官方客户端

官方客户端通常能完整呈现服务器的媒体库、收藏和继续观看功能。不同平台界面和授权会有差异，下面以通用流程说明。

## 安装与登录

1. 从[官方下载中心](https://emby.media/download.html)选择设备。
2. 打开应用，选择添加服务器或手动连接。
3. 按管理员给出的协议、地址与端口连接。
4. 使用服务器本地账号登录；Connect 仅在已关联时使用。

完整地址的拆分示例见[五分钟开始播放](/guide/start#地址怎么拆分)。

## 第一次打开媒体库

检查是否能看到预期的电影、剧集或音乐库。看不到某个库时，先询问管理员是否授权，不要反复重装应用。

进入影片详情，检查是否有多个版本；不同版本可能有不同分辨率、码率和音轨。先用兼容性较好的版本完成测试。

## 播放时优先检查三项

- **质量设置**：先用自动；若有限制码率，可能触发服务端转码。
- **音轨**：无声时切换为设备支持的音轨，注意声道与直通设置。
- **字幕**：优先测试文本字幕；特殊样式或图形字幕可能影响播放方式。

支持的客户端可在播放设置里查看“播放信息”或统计信息。具体名称不固定，重点关注 Direct Play、Direct Stream、Transcoding 及其原因。

## Web 客户端

使用管理员提供的服务器网页入口。若 HTTPS 网页访问 HTTP 资源，浏览器可能阻止混合内容；应修复服务器访问配置，不应关闭浏览器安全保护。

## 退出与更换服务器

在账号或服务器菜单切换。清理缓存、退出登录或卸载应用前，先记录不含密码的连接配置，并确认离线下载是否会受影响。
