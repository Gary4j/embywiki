# 字幕、音轨与 HDR

同一部影片在不同设备上的表现可能不同。遇到异常时，先切换字幕或音轨做对比，再判断是否需要更换客户端或文件版本。

## 字幕：文本与图形

| 类型 | 常见格式 | 需要关注 |
| --- | --- | --- |
| 文本字幕 | SRT、ASS、SSA、VTT | 字体、样式、编码和客户端渲染能力 |
| 图形字幕 | PGS、VobSub 等 | 设备是否可直接呈现，否则可能触发烧录 |

ASS 的复杂样式不一定在所有客户端一致呈现。先切换简单的 SRT 文本字幕，观察是否恢复播放或直放。

## 没有字幕、乱码、不同步

- **没有字幕**：进入影片播放菜单手动选择；确认文件确实包含字幕或有可用外挂字幕。
- **乱码**：外挂文本字幕检查编码，常用 UTF-8；修改前保留原文件。
- **整体延迟一致**：可临时调整字幕偏移。
- **越播偏差越大**：可能字幕对应不同剪辑版或帧率，优先换匹配的字幕。

只有管理员或文件拥有者才能修正服务器端的文件与命名。官方建议外挂字幕与影片基础文件名一致，可附加语言标记，例如：

```text
Example Movie (2026).mkv
Example Movie (2026).zh-CN.srt
Example Movie (2026).en.srt
```

## 音轨：有画面但没有声音

先切换另一条音轨，再检查系统音量和输出设备。音频编码、多声道、直通设置、功放支持范围都可能影响结果。Direct Stream 也可能只转音频而保留视频，这不是完整的视频转码。

## HDR、杜比视界与 SDR

HDR 是一整条能力链：源文件格式 → 客户端 → 设备 → 接口 → 显示器。杜比视界还涉及具体格式配置，不同组合兼容性不同。

遇到发灰、偏色或黑屏时，用 SDR 版本作对照。若由服务器转成 SDR，需检查色调映射是否支持和正确启用，不能只调整屏幕亮度。
