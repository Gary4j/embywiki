# 网络与线路

网络测试要针对**你的设备到这台服务器**的实际路径。宽带测速很快，不代表某个远程服务器也能同样快。

## 带宽和码率

Mbps 是每秒兆比特，MB/s 是每秒兆字节，粗略换算是 **8 Mbps ≈ 1 MB/s**。影片码率会有波动，不能只让可用带宽刚好等于平均码率。

例如平均 20 Mbps 的文件，理论上约对应 2.5 MB/s 数据量，但还需要考虑峰值、协议开销与网络抖动。这是单位示例，不是对任何线路的速度保证。

## 分步比较

1. 同一设备、同一影片，在 Wi-Fi 与移动网络之间做对照，注意流量消耗。
2. 同一网络，用不同客户端测试。
3. 同一客户端，换一段较低码率且兼容的文件。
4. 若管理员提供多条线路，按说明逐条测试，并记录时间与表现。

每次只改变一项，避免把客户端、网络和片源问题混在一起。

## 登录快，播放却慢

海报、账号接口与媒体文件可能经过不同主机或路径。能打开登录页只证明其中一部分可达。请记录具体哪部影片失败、是否所有影片都失败，再联系管理员。

## DNS、证书与代理

DNS 负责把域名映射到地址，不直接提升视频源站带宽。证书错误可能是地址不匹配、证书过期或设备时间错误，不应靠忽略证书验证解决。

VPN、代理或网络加速工具会改变路径，也可能导致绕路。是否需要使用，应根据服务方说明及实际网络比较，不要把“打开代理”当成通用答案。

## 线路地址变更

只使用管理员确认的新地址，保留协议和端口。CNAME 是域名映射，无法替代服务器端域名绑定和 HTTPS 配置。

本站的 `embywiki.pages.dev` 与 `embywiki.gary4j.top` 仅用于文档托管，不是 Emby 播放服务器地址。
