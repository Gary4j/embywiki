# Infuse 连接指南

Infuse 是 Firecore 的播放器，适合希望在苹果设备上使用统一播放体验的用户。它可以连接 Emby，但应用授权和服务器账号仍然独立。

## 开始前

准备服务器地址、端口、用户名和密码，确认服务器允许 Infuse 访问。安装入口：[Infuse 官方网站](https://firecore.com/infuse)。不同系统与版本的菜单名称可能略有变化。

## 添加 Emby 服务器

1. 打开 Infuse 的设置，进入添加文件或添加共享相关入口。
2. 选择 Emby 服务类型；若没有自动发现，使用手动添加。
3. 填写服务器主机、协议、端口及账号。
4. 保存连接，选择需要展示的媒体库或收藏入口。
5. 等待列表加载，播放一段视频并测试字幕、音轨与进度。

本地网络自动发现不到远程服务器是正常情况。按实际地址手动填写，不要把 `https://` 或端口重复填入多个字段。

## 媒体库首次加载较慢

部分模式需要读取较多媒体元数据。等待首次同步结束，避免反复删除并重新添加同一个服务。大媒体库可以按当前版本提供的连接模式和同步选项调整；具体能力以 Firecore 文档为准。

## 播放、字幕与进度

- 打开播放菜单选择音轨和字幕，确认字幕版本与影片对应。
- 测试暂停后退出，在服务器或其他客户端核对进度是否同步。
- 播放失败时用 Emby 官方客户端对照，区分账号、网络与兼容性问题。
- 若出现 Pro 提示，查看当前功能说明；Emby Premiere 不会自动解锁 Infuse Pro。

## 常见误解

Infuse 不能让不可达的服务器自动变得可达，也不能消除源文件过高码率带来的带宽需求。是否直放取决于片源、设备和输出链路，不应只看应用名称。
