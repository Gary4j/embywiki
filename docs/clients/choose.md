# 客户端选择指南

先按设备选择，再根据文件兼容性、使用体验和授权决定是否更换。没有一款客户端能保证所有设备、所有片源都直放。

## 按设备快速选择

| 设备 | 建议起点 | 需要关注 |
| --- | --- | --- |
| iPhone / iPad | Emby 官方应用；也可考虑 Infuse | 播放解锁、字幕渲染、后台与投屏行为 |
| Mac | Emby 官方应用或 Infuse | 支持的系统版本、HDR 显示链路、应用授权 |
| Windows / Linux | 官方下载页列出的桌面应用 | 视频和音频解码、显示输出、Premiere 条件 |
| Android 手机 / 平板 | Emby 官方 Android 应用 | 系统解码能力、音轨兼容性、完整播放授权 |
| Android TV / Fire TV | 设备对应的官方应用 | 遥控器操作、音频直通、版本与授权限制 |
| Apple TV | Emby 或 Infuse | 电视 / 音响格式支持、字幕与动态范围匹配 |
| 临时使用的电脑 | 服务器提供的 Web 客户端 | 浏览器格式支持有限，可能触发转码 |

## 推荐的选择顺序

1. 先用官方客户端验证服务器和账号。
2. 用同一部影片比较字幕、音轨、快进与直放表现。
3. 确认服务端允许所选客户端，并确认应用需要的付费项目。
4. 再决定是否长期使用第三方播放器。

## 官方下载入口

- [Emby 下载中心](https://emby.media/download.html)：按设备进入对应安装页。
- [Infuse / Firecore](https://firecore.com/infuse)：苹果生态播放器。
- [Emby 官方应用文档](https://emby.media/support/articles/Apps.html)：查看设备说明。

社区还会讨论 VidHub、Fileball 等客户端。是否支持 Emby、当前收费和维护状态，请以开发者和应用商店的现行说明为准；本站不提供非官方安装包镜像。

## 浏览器适合什么场景

适合快速验证登录和简单播放。浏览器遇到不支持的封装、音频或视频编码时，服务器可能需要重新封装或转码。网页不能播放，不一定代表原文件损坏；可用兼容的原生客户端对比。
