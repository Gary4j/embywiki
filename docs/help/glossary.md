# 术语速查

| 术语 | 一句话理解 | 延伸阅读 |
| --- | --- | --- |
| Server / 服务端 | 整理并提供媒体库的程序 | [认识 Emby](/guide/intro) |
| Client / 客户端 | 浏览和播放服务器媒体的应用 | [客户端选择](/clients/choose) |
| Emby Connect | 可选的账号关联与服务器发现服务 | [账号说明](/guide/account) |
| Premiere | Emby 的高级功能授权 | [费用说明](/guide/costs) |
| App Unlock | 某些客户端的独立播放解锁 | [费用说明](/guide/costs) |
| 元数据 / 刮削 | 影片标题、简介、海报等信息及其匹配过程 | [认识 Emby](/guide/intro) |
| 容器 / 封装 | 将视频、音频、字幕装在一起的文件组织格式，如 MKV、MP4 | [播放方式](/playback/methods) |
| 编码 | 压缩视频或音频的方式，如 H.264、HEVC、AAC | [播放方式](/playback/methods) |
| 码率 | 单位时间的数据量，常用 Mbps 表示 | [网络与线路](/playback/network) |
| Direct Play | 原文件基本不变地播放 | [播放方式](/playback/methods) |
| Direct Stream | 保留视频，调整封装或其他轨道 | [播放方式](/playback/methods) |
| Transcoding | 解码并重新编码以适配播放条件 | [播放方式](/playback/methods) |
| Burn-in / 字幕烧录 | 把字幕合成到视频画面，通常需要视频转码 | [字幕设置](/playback/subtitles) |
| HDR | 高动态范围，需要片源和显示链路支持 | [画面设置](/playback/subtitles) |
| Tone Mapping | 将 HDR 亮度和色彩范围映射到目标显示范围 | [画面设置](/playback/subtitles) |
| 直通 / Passthrough | 将音频交由下游设备解码 | [电视与大屏](/clients/tv) |
| 并发播放 | 同时活跃的播放会话，不等于已登录设备数 | [账号说明](/guide/account) |
| DNS / CNAME | 域名解析及别名映射，不代表媒体加速 | [网络说明](/playback/network) |
