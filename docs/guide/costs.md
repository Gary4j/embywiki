# 费用与授权

Emby 使用中可能出现三类费用，它们解决不同问题，不能相互替代。

## 先看这张对照表

| 项目 | 买到什么 | 不等于什么 |
| --- | --- | --- |
| 服务器访问服务 | 某个服务器在约定期限内的访问权限 | Emby 官方会员或客户端内购 |
| Emby Premiere / App Unlock | 对应的 Emby 功能或客户端播放解锁 | 任何服务器的媒体库账号 |
| Infuse 等第三方应用授权 | 该应用的付费功能 | Emby Premiere 或服务器订阅 |

Emby Premiere 由服务器安装有效密钥启用，连接的服务器状态决定相关功能是否可用。各平台支持的功能不同，最终以[官方功能矩阵](https://emby.media/support/articles/Premiere-Feature-Matrix.html)和当前应用商店说明为准。

## 能看到海报，为什么播放提示购买

浏览媒体库和完整播放可能使用不同授权条件。先确认：

1. 你连接的是哪台服务器，它是否具备相关 Premiere 权限。
2. 当前客户端是否要求独立解锁，或是否支持使用服务器的 Premiere。
3. 以前的购买属于哪个商店账号、哪个应用和平台。
4. 是否需要在同一个商店账号下执行“恢复购买”。

不要为了消除提示而重复购买未知项目。应用商店内购问题联系应用开发者或商店，服务器账号问题联系服务器管理员。

## 试用应该测试什么

在自己的实际设备、运营商网络和常用时段测试登录、连续播放、字幕、音轨与大屏操作。支持转码、下载、并发播放的承诺，应向服务提供方单独核实。

## 本站为什么不列固定价格

商店地区、版本和授权方式会变化。本站解释收费边界，提供官方入口，不把某一次的价格写成长期有效的规则。
