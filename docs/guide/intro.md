# 认识 Emby

Emby 把服务器上的影音文件整理为可浏览的媒体库，再通过手机、电脑或电视上的客户端播放。**安装客户端只是第一步，你还需要一台可访问的服务器和对应账号。**

## 三个角色，先分清楚

| 角色 | 做什么 | 你需要准备什么 |
| --- | --- | --- |
| Emby Server | 管理文件、海报和元数据，提供访问与播放服务 | 自建服务器，或已有服务器的使用权限 |
| Emby 客户端 | 连接服务器、浏览媒体库、选择音轨与播放 | 与设备匹配的应用或浏览器 |
| 服务器账号 | 决定可见媒体库、播放和下载等权限 | 管理员提供的用户名和密码 |

你可以把服务器理解为书库，客户端是阅读器，账号是借阅证。只有阅读器，不会自动得到书库。

## Emby Connect 是什么

它是可选的账号关联与服务器发现服务。管理员将 Connect 账号与服务器上的用户关联后，你可以更方便地找到服务器。它不会赠送媒体库，也不会替你中转视频。详见[账号与 Emby Connect](/guide/account)。

## Jellyfin、Plex 和 Infuse

- **Jellyfin**：开源的媒体服务器与客户端生态，源于 Emby 的历史开源代码。今天两者已分别发展，不要默认客户端和接口完全兼容。
- **Plex**：另一套媒体管理服务和客户端生态，账号与授权规则独立。
- **Infuse**：Firecore 开发的播放器，可连接 Emby 等媒体服务器。它不是 Emby Server 的替代品，部分功能需要自己的授权。

## 海报和“刮削”从哪里来

“刮削”是根据文件名、年份等信息匹配影片资料，获取标题、简介和海报等元数据。它改善媒体库的展示，但不等于下载影片。海报识别错误需要管理员检查匹配结果；播放器不能凭海报判断文件一定可播放。

## 使用前的小检查

准备一组有效连接信息，确认设备和网络，再选客户端。接下来按[五分钟开始播放](/guide/start)操作。请只访问你拥有或获授权使用的媒体内容。
