# 五分钟开始播放

目标很简单：先用一个客户端播放一段视频，再调整画质、字幕与个性化设置。

## 第一步：准备连接信息

向服务器管理员确认以下信息，保持原样复制，注意首尾空格。

| 信息 | 示例（仅演示） | 注意事项 |
| --- | --- | --- |
| 服务器地址 | `https://media.example.com` | 保留 `https://`，不要把购买页或管理后台当作播放地址 |
| 端口 | `443` 或管理员指定值 | 已在地址里写端口时不要重复添加 |
| 用户名 | `your-username` | 通常是该服务器上的本地账号 |
| 密码 | 由管理员提供 | 区分大小写，不要放进截图 |

::: tip 没有地址？
先联系提供账号的人。本站是使用指南，不提供服务器账号或公共播放地址。
:::

## 第二步：安装客户端

从[Emby 官方下载页](https://emby.media/download.html)或应用商店安装与你的系统匹配的版本。苹果设备也可以选择 Infuse。不了解差别时，先看[客户端选择指南](/clients/choose)。

## 第三步：手动添加服务器

1. 打开应用，找到“添加服务器”“手动连接”或含义相近的入口。
2. 输入服务器地址。如果应用把协议、主机、端口分成不同字段，分别填写。
3. 确认连接后，输入**这台服务器的用户名和密码**。
4. 登录后应看到管理员授权给你的媒体库。

### 地址怎么拆分

完整地址 `https://media.example.com:8443` 对应：协议 HTTPS，主机 `media.example.com`，端口 `8443`。HTTPS 未写端口时通常使用 443；HTTP 通常使用 80。Emby 自建服务器常见端口是 8096 / 8920，但**必须以实际配置为准**。

不要擅自把 HTTPS 改成 HTTP。如果地址带路径前缀，先确认客户端是否支持，并向管理员索取适合该客户端的地址。

## 第四步：完成一次小测试

选择一段常规 1080p 内容，测试连续播放、拖动进度、切换音轨和字幕。先用自动画质；若播放异常，记录提示，不要一口气修改多个设置。

能看海报但不能播放时，请转到[对应排查步骤](/help/troubleshooting#能看到海报但无法播放)。

## 第五步：保存适合自己的设置

- 设置音频与字幕语言偏好；进入具体影片后仍可切换。
- 确认“继续观看”和播放进度能同步。
- 电视端用遥控器测试暂停、快进与返回。
- 在不同网络下分别测试，不把一次成功等同于所有线路都可用。
