# 账号与 Emby Connect

**能登录购买平台，不代表能用同样的账号登录播放器。** 先确认你拿到的是哪一种账号。

## 四种身份不要混用

| 身份 | 用途 | 通常由谁管理 |
| --- | --- | --- |
| 服务器本地账号 | 登录指定 Emby 服务器、访问授权媒体库 | 服务器管理员 |
| Emby Connect 账号 | 关联并发现已授权的服务器 | Emby；关联由服务器管理员设置 |
| 应用商店账号 | 下载、购买或恢复客户端内购 | Apple、Google 等平台 |
| 服务商网站账号 | 订单、续费或服务管理 | 对应服务商 |

## 手动登录还是 Connect

如果管理员给的是“服务器地址 + 用户名 + 密码”，优先手动添加服务器。只有管理员明确启用了 Connect 并完成账号关联，才使用 Connect 登录。

Connect 不会将你自动加入某个服务器，也不会中转播放流量。因此，Connect 能登录而服务器无法访问时，仍要排查服务器和网络。

## 密码忘记了怎么办

- **服务器账号**：联系该服务器管理员，或按其开放的重置流程处理。
- **Connect 账号**：使用 Emby 社区账号找回流程。
- **服务商平台账号**：在对应平台找回，不能用 Connect 重置替代。

不要在尝试失败后连续大量重试，避免触发限流或账号锁定。确认账号是否到期、用户名是否含空格以及地址是否更换。

## 设备数与同时播放数

登录设备、已登记设备和同时播放会话是不同概念。一个账号在两台设备登录，不等于允许同时播放两路。实际限制由服务器配置、服务条款和客户端授权共同决定。

退出不再使用的设备；不要分享密码和包含访问令牌的播放链接。求助时遮挡账号、地址中的私密参数及二维码。
